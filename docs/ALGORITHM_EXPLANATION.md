# Algorithm Explanation

## A* Algorithm

### 基本思想
A*（A-Star）是一種啟發式圖搜索算法，結合了 Dijkstra 算法的最優性保證和貪婪最佳優先搜索的效率。它通過評估函數 f(n) = g(n) + h(n) 來指導搜索方向。

### 核心公式
```
f(n) = g(n) + h(n)
```
- **g(n)**: 從起點到當前節點 n 的實際路徑代價（已知）
- **h(n)**: 從節點 n 到目標點的啟發式估計（預測）
- **f(n)**: 經過節點 n 的估計總代價

### 數據結構
- **open_set**: 待探索的節點集合，按 f(n) 值排序
- **closed_set**: 已探索的節點集合，避免重複訪問

### 啟發式函數設計
使用歐幾里得距離（可採納且一致）：
```python
h = sqrt((x1 - x2)^2 + (y1 - y2)^2)
```
權重 w = 1.0 保證找到最短路徑。w > 1 可加速搜索但可能失去最優性。

### 運動模型
8方向運動（含對角線）：
- 水平/垂直移動：代價 = 1
- 對角線移動：代價 = √2 ≈ 1.414

### 碰撞檢測
基於栅格地圖：將障礙物位置轉換為離散栅格，節點擴展時檢查目標栅格是否被佔用。可通過機器人半徑對障礙物進行膨脹處理。

### 優點
- 保證找到最短路徑（啟發式一致時）
- 搜索效率高於 Dijkstra
- 結果穩定、可重複

### 局限
- 僅適用於離散栅格地圖
- 高分辨率地圖下搜索空間快速增長
- 不適用於高維連續空間

## RRT Algorithm

### 基本思想
RRT（Rapidly-exploring Random Tree）通過在連續空間中隨機採樣並逐步擴展樹結構來探索可行路徑。其核心思想是利用隨機性快速覆蓋搜索空間。

### 算法步驟
1. **Random Sampling**: 在自由空間中隨機採樣一個點。以一定概率（如 5%）直接採樣目標點（goal bias），加速收斂。
2. **Nearest Node**: 在現有樹中找到距離採樣點最近的節點。
3. **Steer**: 從最近節點向採樣點方向擴展一個固定步長，生成新節點。
4. **Collision Checking**: 檢查從最近節點到新節點的路徑是否與障礙物碰撞。若碰撞，丟棄該節點。
5. **Add to Tree**: 若安全，將新節點加入樹中，設置其父節點。
6. **Goal Check**: 若新節點距離目標小於步長，嘗試直接連接到目標。

### 關鍵參數
- **expand_dis**: 步長（如 2.0m），控制樹的擴展速度
- **goal_sample_rate**: 目標偏向概率（如 5%），平衡探索與利用
- **max_iter**: 最大迭代次數
- **robot_radius**: 機器人半徑，用於碰撞檢測的安全邊距

### 碰撞檢測
連續空間圓形障礙物檢測：對於路徑上的每個插值點，檢查它是否在任何障礙物圓的範圍內。
```python
distance = sqrt((ox - px)^2 + (oy - py)^2)
if distance <= obstacle_radius + robot_radius:
    collision!
```

### 優點
- 適用於連續空間和高維空間
- 不需要離散化地圖
- 搜索速度快，特別適合複雜障礙場景
- 概率完備性：若路徑存在，足夠時間後必能找到

### 局限
- 路徑不最優（相比 A*）
- 結果有隨機性，每次運行結果不同
- 路徑可能不平滑（鋸齒狀）
- 在高密度障礙物環境中可能失敗

## A* vs RRT 對比

| 維度 | A* | RRT |
|------|----|-----|
| **地圖類型** | 離散栅格地圖 | 連續空間 |
| **最短路徑** | 保證最優 | 不保證（次優） |
| **結果穩定性** | 確定性，每次相同 | 隨機性，每次不同 |
| **搜索效率** | 開銷隨栅格數量增長 | 開銷隨樹節點數增長 |
| **高維空間** | 不適用（維度災難） | 適用 |
| **障礙物密集** | 大量節點探索 | 可能長時間找不到路徑 |
| **路徑平滑度** | 受栅格分辨率限制 | 較粗糙（需後處理） |
| **實現複雜度** | 中等 | 較低 |
| **適用場景** | 室內導航、栅格地圖 | 機械臂規劃、無人機航跡 |

### 何時選擇 A*
- 有明確的栅格地圖
- 需要最短路徑
- 對搜索時間要求不嚴格
- 需要穩定、可預測的結果

### 何時選擇 RRT
- 連續空間或高維空間
- 障礙物稀疏但幾何複雜
- 不需要最短路徑（可行即可）
- 需要快速響應

### 工程實踐中的組合使用
- 先用 RRT 快速找到可行路徑
- 再用路徑平滑或局部優化改善路徑質量
- 使用 RRT* 獲得漸進最優解
