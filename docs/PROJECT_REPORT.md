# 基於 A* 與 RRT 的移動機器人路徑規劃仿真系統

## 一、項目背景

移動機器人導航是機器人領域的核心問題之一。機器人在未知或部分已知的環境中，需要從起點安全、高效地移動到目標點，同時避開環境中的障礙物。路徑規劃（Path Planning）算法正是解決這一問題的關鍵技術。

常見的路徑規劃算法分為兩大類：
- **基於搜索的方法**（如 A*、Dijkstra）：在離散栅格地圖上搜索最優路徑。
- **基於採樣的方法**（如 RRT、PRM）：在連續空間中通過隨機採樣構建可行路徑。

本項目實現了這兩種代表性算法，並設計了可視化、批量測試和性能對比框架。

## 二、項目目標

1. 實現 A* 與 RRT 兩種路徑規劃算法
2. 構建模塊化的地圖生成、碰撞檢測與可視化系統
3. 設計批量測試框架，對比不同場景下的算法表現
4. 導出 CSV 測試結果，支持數據驅動的算法評估
5. 生成規範的技術文檔和演示圖片

## 三、系統架構

```
path_planning_simulator/
├── algorithms/       # 算法核心：A*、RRT、碰撞檢測
├── maps/             # 地圖系統：栅格地圖、障礙物生成
├── evaluation/       # 評估系統：指標計算、批量測試
├── visualization/    # 可視化：Matplotlib 綁圖
├── outputs/          # 輸出：圖片、CSV、摘要
├── assets/           # 展示圖片（用於 README）
├── docs/             # 項目文檔
└── main.py           # CLI 主入口
```

各模塊職責：
- **algorithms**: 純算法實現，不依賴可視化
- **maps**: 地圖數據結構，支持栅格化和連續空間
- **evaluation**: 指標計算和批量測試編排
- **visualization**: 將算法結果轉為 Matplotlib 圖表

## 四、核心功能

### 1. 地圖生成
- 二維栅格地圖，可配置大小和分辨率
- 邊界牆自動生成
- 隨機圓形障礙物生成（可配置數量、大小、隨機種子）
- 室內牆壁佈局生成

### 2. A* 路徑規劃
- 8方向運動模型（含對角線，代價為 √2）
- 歐幾里得距離啟發式函數
- 機器人半徑障礙物膨脹
- Open/Closed set 管理

### 3. RRT 路徑規劃
- 連續空間隨機採樣
- 目標偏向採樣（goal bias = 5%）
- 步長限制的節點擴展（steer）
- 路徑插值碰撞檢測

### 4. 碰撞檢測
- 栅格佔用檢測（A*）
- 連續空間圓形障礙物檢測（RRT）
- 路徑線段插值檢測

### 5. 可視化
- A* 路徑 + 障礙物 + 起終點綁圖
- RRT 搜索樹 + 最終路徑綁圖
- A* vs RRT 同場景對比圖
- 批量測試統計圖

### 6. 批量測試
- 多組地圖配置自動化測試
- 指標計算：路徑長度、運行時間、成功率、搜索節點數、平滑度、安全距離
- CSV 結果導出
- Benchmark Summary 自動生成

## 五、算法實現

### A*
A* 是一種啟發式搜索算法，使用評估函數 f(n) = g(n) + h(n)：
- g(n): 從起點到節點 n 的實際代價
- h(n): 從節點 n 到目標的啟發式估計（歐幾里得距離）
- 維護 open set（待探索節點）和 closed set（已探索節點）
- 每次從 open set 中選擇 f 值最小的節點進行擴展

### RRT
RRT（Rapidly-exploring Random Tree）是一種基於採樣的路徑規劃算法：
1. 在空間中隨機採樣一個點（以 5% 概率直接採樣目標點）
2. 從樹中找到最近的節點
3. 從最近節點向採樣點方向擴展一個步長（steer）
4. 檢查新路徑是否與障礙物碰撞
5. 若安全，將新節點加入樹中
6. 重複直到到達目標區域

## 六、實驗設計

測試配置：
- 地圖大小：50×50m、80×80m
- 障礙物數量：15、25、30
- 網格分辨率：1.0m、2.0m
- 機器人半徑：0.5m、1.0m
- 隨機種子：42、123、456（保證可重複性）

## 七、實驗結果

| Algorithm | Success | Path Length (m) | Time (ms) | Nodes Explored |
|-----------|---------|-----------------|-----------|----------------|
| A*        | 2/3     | 57.15 ~ 107.20  | 4.0 ~ 42.1 | 99 ~ 1962     |
| RRT       | 1/3     | 66.72           | 5.0 ~ 94.5 | 0 ~ 795       |

詳細結果見 `outputs/results/batch_results.csv` 和 `outputs/results/benchmark_summary.md`。

## 八、項目亮點

- **模塊化架構**: algorithms / maps / evaluation / visualization 四層分離
- **算法對比**: 同一地圖下直觀對比 A* 和 RRT 的路徑差異
- **批量測試**: 自動化多場景測試，支持參數矩陣
- **CSV 導出**: 結構化結果數據，可用於進一步分析
- **可視化展示**: 高質量 Matplotlib 圖表，適合直接放入報告
